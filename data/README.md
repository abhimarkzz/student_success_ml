# Data directory

Raw datasets are not bundled in the repository. Use the official/public download scripts.

## UCI Student Performance
Place files here:

`data/raw/uci_student_performance/student-mat.csv`
`data/raw/uci_student_performance/student-por.csv`

Official source: https://archive.ics.uci.edu/dataset/320/student+performance

## Placement benchmark
The adapter can download the public benchmark from:
https://huggingface.co/datasets/Krooz/Campus_Recruitment_CSV

Do not describe this benchmark as institutionally verified real-world student data.

## Institutional placement dataset
For your final project, the preferred production/research path is an anonymized CSV exported from your college placement/ERP system, subject to institutional permission and applicable privacy rules.
